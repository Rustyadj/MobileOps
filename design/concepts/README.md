# Design concepts

The early concept mockups previously stored here (`operations-command-center.png`,
`rentals-table-detail.png`) showed dollar amounts — a "RENTAL REVENUE (MTD)"
KPI tile and a per-rental pricing table with rate/subtotal/tax/total figures.
That contradicts the product's no-dollar-amounts-in-the-UI decision (see
`memory/PRD.md`), so they were removed rather than left around as a stale
reference for future design work. Recovered from git history if needed, but
don't use them as a starting point without stripping every dollar figure
first.
